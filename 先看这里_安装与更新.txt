抓到你啦 4.1.0 安装与更新

本版新增：
1. 截图后，在“以图找相似”页面直接 Ctrl+V 粘贴，不必先保存文件。
2. 默认只搜一个平台；选小红书就只收集小红书站点限定检索的候选。多平台模式继续保留。
3. 新增拼多多、唯品会，天猫保持独立；支持链接识别和已加载商品图读取规则。
4. 字体和按钮放大，平台选中高亮。
图片检索通过 Bing／Google Lens 限定所选平台站点，不是平台原生上传搜图接口，受公开收录影响。

新功能：以图／视频找相似
展开工作台 → 左侧“以图找相似” → 上传图片或视频 → 选参考画面与平台
→ 选择 Bing 或 Google Lens → 只搜所选平台 → 收录候选／收录并挑图。
视频在本机抽 5 帧，每次可选 1–3 帧；不会上传整段视频。
点击开始后，仅把所选参考图或关键帧发送到你选的图片搜索服务。
首次需要授予该搜索服务的网站权限。出现验证时打开搜索页处理，再继续收集。
搜索依赖服务可访问性与公开收录，不保证平台全量结果或语义完全相似。

普通使用：
解压 → Chrome/Edge 扩展管理 → 开发者模式 → 加载已解压的扩展程序
→ 选择 xhs-note-desk 文件夹（其中有 manifest.json）。
固定图标后，直接打开小红书、Pinterest、抖音作品或淘宝天猫商品。
识别结果自动进入素材库，不必复制粘贴；下载仍由你点击开始。

旧版升级：
先备份清单 → 用新版文件覆盖原 xhs-note-desk 目录 → 扩展管理页重新加载。
不要先卸载，也不要每次换一个安装路径。已有清单自动继续使用。
如自动收录未立即出现，刷新一次作品页。
本版增加拼多多／唯品会站点权限，浏览器提示时按需允许。
旧版参考搜索任务请重新开始；已有素材清单继续保留。

笔记内挑图下载（新版）：
点击一篇笔记的卡片或“挑图下载” → 勾选想要的图片 → 下载所选图片。
默认不勾选；支持放大查看、上一张/下一张、全选、反选和清空。
例如一篇有 8 张图，只勾第 2、5 张，就只保存这两张。
图片未加载时，点“重新解析图片”后再勾选。

三个独立入口：
分类管理：新增/改名/删除/批量归类。
图片批量抓取：选来源 → 抓取 → 预览缩略图 → 勾选 → 下载所选图片。
一键下载：确认作品与图片/视频类型 → 查看数量 → 开始 → 下载队列看进度。

“用户”列始终为发布该条作品的账号名字。
无法识别时留空，可手动编辑；电商平台使用页面可识别的店铺名。
原来的三列复制、手动粘贴、CSV、备份和跨平台检索都保留。

把安装包发给别人：
朋友首次按上面安装。以后新版下载后覆盖原目录并重新加载，不用卸载重装。
GitHub Releases 可以作为下载位置，但仅刷新网页不能自动取得新代码。
本次尚未上传 GitHub，也未上架商店。

正式自动更新：
以后可在 Chrome/Edge 商店创建一次条目，朋友从商店安装。
你在原条目提交高版本，审核发布后浏览器获取更新；已下载新版可刷新启用。
当前“检查更新”会识别本地解压安装，并显示真实的更新方式。
