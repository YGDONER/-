抓到你啦 4.2.0 安装与更新

本次新增 Instagram（ins）平台，保留自动收录、分类、逐张选图下载、三列复制、CSV、备份、截图 Ctrl+V 和视频本机抽帧。

【首次安装，Chrome / Edge】
1. 把 ZIP 解压到一个长期保留的文件夹。
2. Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
3. 开启右上角“开发者模式”。
4. 点“加载已解压的扩展程序”，选解压后的 xhs-note-desk 文件夹（里面有 manifest.json）。
5. 点击浏览器拼图按钮，将“抓到你啦”固定到工具栏，点击图标打开。
ZIP 不是可以双击自动安装的程序，也不是签名的商店 CRX。

【更新已有版本】
1. 在旧版插件中导出 JSON 备份。
2. 把新版 xhs-note-desk 里面的文件全部覆盖到原来的同名扩展文件夹。
3. 在扩展管理页找到原来的“抓到你啦”，点重新加载。
4. 新增 Instagram 网站访问权限若需要启用，按浏览器提示操作。
保持原路径，不要卸载旧版，原素材和自定义分类继续保留。
本地解压版的刷新不下载远程代码。请从同一 GitHub 仓库的 Releases 下载新版，覆盖原目录后重新加载。

【使用 ins】
在自己的浏览器中打开具体帖子或 Reels，等待加载；自动收录开启时会保存到素材库的 Instagram（ins）分类。
“用户”取该条帖子的发布账号名字，不是当前登录者。
打开作品的图片选择界面，勾选自己要的图片后下载。多图帖若仅有 DOM 图片可读，切换轮播后重新识别会补充已加载图片。
视频仅保存可读的文件直链。没有可用直链时显示原因，不会虚报下载成功。

【参考图 / 视频检索】
截图后在“以图找相似”页面按 Ctrl+V，或上传图片／视频。视频在本机抽帧，最多选 3 帧。
选择目标平台，点“前往…”，插件直接打开该平台，检查原生以图搜图入口。
本版不再使用必应或 Google。只有找到专用于图片检索的上传框才发送参考画面，不上传整段视频，不使用发帖上传框。
网页未开放原生搜图入口、尚未登录或验证未完成时，显示待处理。不会把普通关键词结果或首页推荐内容当成相似图片。
Instagram 网页端以图搜图入口尚未确认，插件会明确提示，不上传参考图；其收录、分类、挑图下载和独立关键词检索继续可用。
目前尚未完成各平台登录态原生搜图的实站验证，平台网页变化也可能使入口不可用。

【原有功能】
P站是 Pinterest。原有小红书、抖音、淘宝、天猫、拼多多、唯品会及按站点授权的网页采集保留。
三列复制顺序为 素材地址 → 标题 → 用户。下载文件按 平台 / 分类 / 发布账号 / 作品标题 整理。
