# 抓到你啦 4.2.0

**[下载安装包 v4.2.0](got-you-v4.2.0.zip?raw=1)** · [版本发布页](https://github.com/YGDONER/-/releases) · [完整源码与测试](source-v4.2.0.zip?raw=1) · [安装与更新](先看这里_安装与更新.txt)

普通用户下载“安装包”，解压后加载 xhs-note-desk 文件夹即可。开发者源码包包含 extension/、tests/ 和 publisher/；商店提交包仅用于扩展商店上传。

新增 Instagram（ins），并把参考图片／视频帧检索改为只使用所选平台的原生网页。

## 本次更新

- Instagram 独立平台分类、筛选、关键词检索入口、帖子／Reels 自动收录和批量解析。
- 支持 `/p/`、`/reel/`、`/reels/`、`/tv/` 及带账号前缀的分享链接。同一 shortcode 去重，区分大小写。
- 发布账号取当前帖子的作者名字；名字不可用时取作者 username，不使用登录者、评论者或推荐帖作者。
- 从当前帖子已加载的结构化数据读取轮播图片和可用的视频直链，优先较高分辨率。缩略图仍按封面处理。
- 只有 DOM 图集可读时，读取本帖已加载的图片；切换轮播再识别会补充图片。不会把整个首页的推荐图片混进本帖。
- 保留逐张勾选下载、全选／反选／清空、预览、下载队列、分类、截图 Ctrl+V、视频本机抽帧、三列复制、CSV 和 JSON 备份。
- 旧的通用网页 ins 记录补上平台标签，保留 ID、作者和自定义分类。

## 安装与升级

Chrome／Edge 解压安装：解压安装包，打开扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”，选 `xhs-note-desk` 文件夹。

已有用户：先备份清单，用新版 `xhs-note-desk` 文件夹内的文件覆盖原安装目录，再点该扩展的重新加载。保持同一目录与扩展身份，无需卸载。浏览器提示 Instagram 新增网站访问权限时按提示启用。

本地解压版点击网页刷新不会自动下载新代码。请从同一 GitHub 仓库的 Releases 下载新版，覆盖原目录后重新加载。商店版需要正式上架后由浏览器获取更新。

## ins 使用方法

1. 在你自己的浏览器中打开可访问的 ins 帖子／Reels，等待内容加载。自动收录开启时，帖子信息进入素材库。
2. 在素材库选择 Instagram（ins），进入作品的图片选择界面；勾选需要的图片后下载。
3. 图片不足时，切换原帖轮播，重新识别当前作品；仅 DOM 可读时会累积已加载图片。
4. 视频仅支持页面已提供的文件直链。Blob、分段流、不可访问或需要额外权限的媒体不会伪造下载成功。
5. 关键词检索是独立功能，打开 Instagram 自己的搜索页；可用结果取决于当前网页、账号和平台页面。

## 参考图片／视频原生检索

不再使用 Bing 或 Google Lens。选择平台后点“前往…”，首个目标平台页面会打开到前台。只有识别到明确用于图片搜索的上传框时，插件才发送选中的参考副本／视频帧；不会使用普通发帖上传框。

- 小红书、Pinterest、抖音、淘宝、天猫、拼多多、唯品会：检查当前网页的原生图片搜索入口。没有可确认的入口、需要登录或页面尚未返回搜图结果时显示待处理，不会改用其他站点或普通关键词搜索。
- Instagram：尚未确认网页端有可用的参考图上传检索入口。该选项会打开 ins 并明确提示限制，不发送参考图，也不把 Explore 推荐内容当成相似结果。
- 当前没有任何平台的登录态原生搜图完整实站验证结果；入口检测和结果流程已通过模拟页面测试。不能保证每个平台网页都开放此功能。
- 只有平台原生图片检索结果的可确认页面才收集候选；再按所选平台与具体作品链接过滤。候选须由你勾选后收录，账号在原帖读取后补全。
- 原生流程需要你手动处理时，在对应平台完成本次参考图搜图，再回插件点“完成本次原生搜图后继续”。没有网页入口时无法用这个按钮补出能力。
- 老版站外搜图任务在升级后停止，清空其暂存候选；素材库里已经收录的作品继续保留。
- 图片选择／Ctrl+V、视频抽帧均在本机完成。视频不整段上传，最多选择 3 帧，原始文件不上传。

## 发布账号与原功能

“用户”始终是链接对应作品的发布账号名字。电商为当前商品可识别的店铺名字。三列复制顺序：素材地址 → 标题 → 用户。

P站为 Pinterest。支持平台还包括小红书、抖音、淘宝、天猫、拼多多、唯品会；其他网页需在页面采集中按站点授权。既有素材、分类、下载和备份数据沿用原存储键。

下载路径：`下载文件夹 / 抓到你啦 / 平台 / 分类 / 发布账号 / 作品标题`。

## 开发与验证

需要 Node.js 18+，测试不依赖安装第三方包：

```sh
node --test tests/*.test.mjs
python3 publisher/build_release.py --previous 4.1.0
```

`extension/` 为扩展源码；`tests/` 为回归与新功能测试；`publisher/` 仅打本地安装包和商店提交包。不包含 GitHub Actions 自动写入主分支的流程。

验证范围与实站限制见 `验证说明.md`。不要把模拟测试通过理解为所有平台都已实站搜图成功。
