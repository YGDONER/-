# 抓到你啦 4.4.0

**[下载安装包](https://github.com/YGDONER/-/releases/download/v4.4.0/got-you-v4.4.0.zip)** · [版本说明](https://github.com/YGDONER/-/releases/tag/v4.4.0) · [完整源码与测试](https://github.com/YGDONER/-/releases/download/v4.4.0/source-v4.4.0.zip)

Chrome／Edge 浏览器扩展。本次构建保留原有的平台收录、账号识别、分类、逐张挑图、批量抓取、视频直链下载、截图 Ctrl+V、视频抽帧、三列复制和 JSON／CSV 导出。

## 这次更新

- 新收录、页面采集和解析时，标题超过 200 个 Unicode 字符自动跳过。200 个字符保留，标点、标题内部空格计入；不截断后强行入库。已有素材保留。
- 收录和下载分开控制。顶部随时暂停／继续收录、暂停／继续下载、结束下载；下载队列还有“结束本批下载”。
- 结束下载先拦住等待队列和“解析后下载”任务，再取消浏览器中的未完成文件。后台迟到的启动结果或解析结果不会接续本批任务。已完成文件和素材库保留。
- 首次从旧版升级，有未完成队列时先暂停，用户点击继续后再恢复。结束后新加入的下载也先等待，点击“继续下载”启动。
- 参考搜图选择当前已打开网页后自动锁定平台，复用该网页；不使用必应、谷歌或其他站外搜图引擎，不自动跳转到其他平台。
- 新增“本页图片找相似”：在本机比较当前可视区域最多 40 张完整显示的帖子图片，按颜色与画面结构排序。IG 也可用；这不是全站语义检索，不能搜索未加载的所有 IG 帖子。
- 保留“当前平台原生搜图”：只有网页实际开放搜图专用上传入口才提交参考副本；缺少入口、需要登录或验证时明确提示。IG 暂无已验证的网页原生上传搜图入口，不向其发送参考图。

## 安装与更新

首次安装：解压 got-you-v4.4.0.zip，在 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions 开启开发者模式，加载含 manifest.json 的 xhs-note-desk 文件夹。

已有版本：先导出 JSON 备份，将新版 xhs-note-desk 内的文件覆盖原来同一个安装目录，再点击扩展管理页的“重新加载”。不要先卸载，保持原路径和扩展身份可继续使用素材库。无需 Node、Python 或命令行。本地解压版需要下载新文件，网页刷新不会自动取得新版代码。

## 能不能让以前安装的电脑刷新就更新？

**目前不能。** 之前从 GitHub 下载 ZIP 并“加载已解压扩展”的电脑，刷新网页或点击“重新加载”只会读取电脑上已有文件，不能从 GitHub 取得新代码。这次需要下载新版、覆盖原目录后重新加载。

今后需要免重复下载，应通过官方扩展商店分发。先完成开发者注册和扩展审核，旧版用户导出 JSON 清单，安装商店版后导入；以后由浏览器自动检查并安装已审核的新版本，必要时刷新平台网页或插件工作台即可使用。更新存在检查和审核时间，不能保证发布后立刻生效。

目前尚未上架 Chrome／Edge 商店，没有向其他电脑远程推送或同步，也没有启用远程脚本更新。已准备 got-you-store-v4.4.0.zip 供后续商店提交，它不是一份已上架的安装包。完整说明见 [AUTO_UPDATE.md](AUTO_UPDATE.md)。

## IG 本页找相似

1. 打开可访问的 IG 帖子或图片列表，让图片加载并完整显示。无登录也能看到的公开内容可以比较；本插件不能读取被登录界面或访问限制挡住的图片。
2. 在目标平台页面点击浏览器工具栏的“抓到你啦”，再打开“以图找相似”。这样浏览器可授予本次页面读取权限。
3. 上传参考图或截图 Ctrl+V，也可上传视频选择 1–3 个参考帧。
4. 网页列表选择该 IG 页面，方式选择“本页图片找相似”，点击开始。插件短暂切到目标页读取画面后返回工作台，参考图不上传。
5. 可以调低相近度下限放宽结果，或滚动平台页显示更多图片后再次匹配。候选仅供参考，不表示同一人物、作者或作品；收录后可去原作品识别账号、挑选图片下载。

## 下载与权限

只保存图片和视频，保留 4.3.0 的地址、响应类型、浏览器风险状态检查。程序不关闭安全防护、不添加排除项、不接受危险下载。4.4.0 尚未重新进行独立杀毒扫描，旧版检测结果不能代表本包或所有电脑都会放行。

没有增加权限；仍为 activeTab、scripting、storage、clipboardWrite、downloads。activeTab 用于用户发起的本页画面读取。完整画面不落盘、不发给服务器，比较后释放；参考副本和候选保存在本机，可通过“清空本次参考与结果”移除。
