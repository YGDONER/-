## 4.3.0 的改动

- 保留 Instagram（ins）独立平台入口、分类和筛选，支持当前帖子、Reels、轮播图与发布账号识别。
- 下载前检查资源地址；对旧队列和下载重定向执行同样检查，拒绝程序、脚本、网页、SVG 活跃文档和压缩包。
- 检查服务器报告的媒体类型。错误网页不会显示“下载完成”；未提供媒体类型的 CDN 仍由浏览器安全检查处理。
- 新增“安全检查中／已拦截”状态。浏览器或安全软件提示风险时停止任务，保留原因，拦截任务不提供自动恢复或重试。
- 限定扩展消息来源。第三方网页不能调用素材库修改、导出或下载命令。
- 扩展页面禁止远程脚本、动态执行、脚本网络连接、插件对象、iframe 和表单提交。所有运行代码都来自安装包，平台网页中的原生搜图按原流程操作。
- 源码整理为可读格式；构建使用固定文件时间与顺序，便于按 SHA256 对照最终文件。

这些改动不能证明此前的 Windows 11 报毒已修复，也不能保证所有安全软件均放行。最终安装包的实际 Defender 检测记录见该版本发布页；程序不会关闭安全防护、添加排除项或替用户接受危险下载。

## ins 怎么用

1. 在自己的浏览器登录并打开可访问的 `instagram.com/p/…`、`reel/…`、`reels/…` 或 `tv/…` 作品页，等内容加载。
2. 开启自动收录后，作品进入素材库；也可用“采集当前页面”。发布账号取当前作品作者，名字不可用时取其 username。
3. 点击作品的“挑图下载”，逐张勾选图片并预览。轮播图片没加载齐时，切换原帖轮播后重新识别，会补充本帖已加载图片。
4. 视频只保存页面已提供的文件直链。Blob、HLS、DASH 和受保护媒体不伪造下载成功。

结构化数据、登录状态与网页版本会影响可用性。已验证的是模拟页面与队列流程，尚未完成登录态 ins 全流程实站测试。网页端“参考图上传找相似”入口尚未确认，选择 ins 会打开平台并说明限制，不发送参考图。

## 原有功能

支持 Pinterest（P站）、小红书、抖音、淘宝、天猫、拼多多、唯品会和按站点授权的通用网页。保留自动收录、分享文案解析、分类管理、图片批量抓取、笔记内逐张选图、预览、下载队列、截图 Ctrl+V、视频本机抽帧、三列复制、CSV 与 JSON 备份。

“用户”是该作品的发布账号名字，电商取可识别的当前店铺名字。复制顺序为 **素材地址 → 标题 → 用户**。

参考检索只前往用户指定的平台，不使用必应或 Google。只有确认图片搜索专用上传框才交给该平台选中的参考副本；没有入口、需要登录或验证时显示待处理，不使用发帖入口，不把普通推荐或关键词结果当成相似结果。各平台登录态原生搜图尚未完整实站验证。

## 安装与升级

首次安装：解压安装包，Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启开发者模式，加载含 `manifest.json` 的 **xhs-note-desk** 文件夹。无需 Node、Python 或命令行。

升级：先导出 JSON 备份，将新版 xhs-note-desk 内文件覆盖到原来的同一个目录，再点击扩展管理页的“重新加载”。保持原扩展身份和目录可沿用已有清单，不要先卸载。

本地解压版刷新网页不会自动下载新版代码，须下载新版并覆盖原目录。尚未上架 Chrome／Edge 扩展商店。
