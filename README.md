## 这版改好了什么

- 截图后，在“以图找相似”页直接按 **Ctrl+V**，立即显示参考图；继续支持上传、拖入图片和视频抽帧。
- 默认 **只搜一个平台**，初始为小红书。选哪个平台，按钮就显示“只搜哪个平台”；也可切换“多个平台”。
- 上传页面只建立图像上下文，不收集其全网候选。每个参考画面分别创建所选平台的站点限定检索任务；结果只保留本次所选平台。
- 新增拼多多、唯品会的平台识别、商品链接去重和页面商品图集读取规则。天猫继续保留独立入口。
- 字体、按钮和复选框整体放大，辅助文字加深；平台选中后高亮，检索范围和关键操作更醒目。
- 保留已有自动收录、发布账号识别、分类管理、图片批量抓取、视频抽帧、笔记内挑图下载、三列复制、CSV、JSON 备份、关键词检索及下载队列。

## 快速安装

1. 解压安装包，保留 `xhs-note-desk` 文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启开发者模式，点击“加载已解压的扩展程序”。
4. 选择 **含 manifest.json 的 xhs-note-desk 文件夹**。固定工具栏图标后即可使用。

无需 Node、Python 或命令行即可使用插件。外层完整发行包与“商店上传包”用途不同：本机安装请选择 xhs-note-desk 文件夹。

## 从旧版升级

先在旧版导出 JSON 备份，再将新版 `xhs-note-desk` 内文件覆盖到**原来的扩展目录**，在扩展管理页点击“重新加载”。保留同一路径与原扩展身份，不要先卸载。旧版清单自动迁移／继续使用。升级后如浏览器提示新增网站权限，按浏览器要求处理；已有网页会尝试注入自动收录脚本，必要时刷新该作品页。

## 上传参考找相似

1. 打开完整工作台，选择左侧 **以图找相似**（也支持视频）。从工具栏小窗口点击这个入口会展开工作台。
2. 截图后在此页面直接按 **Ctrl+V**，不必先保存图片。也可上传或拖入 JPG／PNG／WebP 等图片（≤25MB），或浏览器可解码的 MP4／WebM 等视频（≤500MB）。普通文本粘贴和原来的分享文案整理保留。
3. 图片生成本机搜索副本；视频在本机按时间抽取 5 帧，默认选第 1、3、5 帧。可改选 1–3 帧；只搜选中的画面，不上传整段视频。
4. 默认“只搜一个平台”，选择小红书、Pinterest（P站）、抖音、淘宝、天猫、拼多多、唯品会或其他网站。需要联合检索时切换“多个平台”；补充描述可以留空。
5. 选 Bing 视觉搜索或 Google Lens，再点击 **只搜所选平台**（如“只搜小红书”），多平台模式则点击“搜索所选 N 个平台”。首次会请求所选搜索服务的站点访问权限；未授权时不会发送参考图。不需要 API 密钥。
6. 插件通过搜索服务的网页上传入口传入图片副本，仅取得图像上下文；不将上传页的全网候选加入结果。每个参考画面都创建本次所选平台的站点限定检索页，并发为 2。单张图片、单个平台通常为 1 个准备页加 1 个平台检索页；视频选择 3 帧、1 个平台则为 3 个准备页加 3 个检索页。搜索页保留供你查看。
7. 候选按平台筛选、按命中的参考画面数排序；不会把搜索返回顺序转换为语义相似百分比。可勾选候选选择分类后收录，或点 **收录并挑图**：解析原作品后逐张选择下载。

需要 Cookie 选择、登录或验证时，任务显示待处理。展开“各平台与画面的检索状态”，点击“打开搜索页”处理，再回工作台点“处理后继续收集”。搜索标签页关闭后，请重新开始检索。上传入口变化时可在搜索页手动上传当前参考图，再继续收集。

**检索范围：**通过 Bing／Google Lens 限定所选平台的站点检索，并在收集结果时再次按来源平台过滤。当前不是平台原生上传搜图 API，也没有各平台全量数据库。未收录、登录可见或未公开的笔记可能搜不到；“0 条”不等于没有相似作品。视频检索依据所选静态画面，不比较音频、完整动作或剧情。搜索结果需查看原作品确认。

**参考数据：**点击开始后，所选搜索服务会接收已选图片副本／关键帧；清单不会发送给发布者。所选参考副本与本次结果保存在本机，便于刷新后查看或继续。点“清空本次参考与结果”可移除这些本机数据，已收录到素材库的作品保留；不会删除搜索服务已接收的数据。JSON 清单备份不包含参考图片或视频。

旧版 4.0 的参考任务需重新开始，才能使用本版指定平台规则；已收录作品不受影响。拼多多、唯品会旧记录若原来归为通用网页，会补上平台标识，并保留原 ID、账号名字和自定义分类。

## 日常使用

- 先打开作品。自动识别后，工作台“自动收录”页显示最近填入的链接、标题和发布账号。
- 只想保存一篇笔记中的部分图片：点卡片上的“挑图下载”，例如只勾第 2、5 张，再点“下载所选图片（2）”。图片不全时点“重新解析图片”。
- 要修改分类：去“分类管理”。在素材库先勾选作品，可以批量归类；未勾选时作用于当前筛选结果。
- 只想抓图片：去“图片批量抓取”，选择网页或批量作品，预览后勾选保存。
- 要整组保存：去“一键下载”，确认范围和类型，再开始。下载队列显示浏览器实际状态。
- 原来的粘贴入口在自动收录页“手动补充链接／分享文案”中，可展开使用。
- 三列复制的顺序始终是：**素材地址 → 标题 → 用户（发布账号名字）**。

例如：标题“叫我什么 姐姐？”对应用户“卿颂Fafa📷（厦门陪拍）”。

## 分享和更新

本仓库提供完整源码与安装包，并通过 Releases 按版本分发。**尚未提交 Chrome／Edge 扩展商店审核**。

可以直接分享本仓库或 Releases 下载链接。朋友首次安装后，新版只需下载、覆盖原目录并重新加载，不需要卸载重装。仅刷新网页或工作台数据不会下载新插件代码。

如需浏览器自动取得完整代码更新，后续可以发布到 Chrome／Edge 扩展商店；从同一商店条目持续发新版。插件已经接入浏览器的“检查更新／刷新启用新版”，本地解压版会清楚显示其更新方式。首次正式发布仍需你的开发者账号、展示材料和公开的隐私说明页面。

## 解析和下载范围

读取你当前浏览器可访问的作品数据与页面资源，支持图片和视频文件直链。其他网站需先在“页面采集”中授权该网站；授权后的文章／作品页面可尝试通用识别。页面结构、登录、验证和资源有效期会影响结果，不能保证所有平台的全部作品都能下载。

封面默认不等同于图集原图；HLS／DASH、加密视频或仅有 Blob 的播放器不在本版文件直链下载范围。文件按原资源保存。可用图片／视频地址过期时先重新解析，再重试。已经完成的下载默认去重；需要再次下载可先清理已结束队列。

新增平台页面读取以浏览器实际可访问、已加载的内容为准；店铺名字识别不到时留空。登录、验证码、图片有效期和页面变化可能影响结果。唯品会登录后页面未完成实站验证。

## 保存位置和数据

`浏览器下载文件夹 / 抓到你啦 / 平台 / 分类 / 发布账号 / 作品标题`

清单在本机浏览器存储，没有自建解析服务器或云同步；以图检索按上方说明将所选参考画面发送给你选择的搜索服务。详细说明见插件内“使用说明”和 `xhs-note-desk/privacy.html`。JSON 备份包含清单与资源链接，不含媒体文件、浏览器下载历史或其他人的登录状态。

## 开发者与后续发布

完整源码位于 `source-release.zip` 中，解压后可直接查看 `xhs-note-desk`，运行 `node --test 开发检查/tests/*.test.mjs`。安装包中也保留可读源码与检查文件。

- `xhs-note-desk`：插件源码，运行无外部依赖。
- `开发检查/tests`：92 项自动化检查。
- `publisher/build_release.py`：校验并生成安装包和商店上传包。
- `发布资料`：安装、分享、版本说明与更新步骤。
- `验证说明.md`：测试覆盖及尚未验证的实际环境。

本次采用手动 GitHub Releases 发布。后续做好新版后，先运行检查、生成更高版本的安装包，再在同一仓库创建新版本 Release 并上传附件。未启用 GitHub Actions 自动写入仓库或自动提交代码。
